# CommHub Pro - Quick Reference Card

## 🚀 Quick Start (30 seconds)

1. **Login** → Navigate to **Media** → Click **CommHub Pro**
2. **Enter room name** (e.g., "team-meeting")
3. **Click "Join Room"** → Allow camera/microphone
4. **Share room name** with participants
5. **Done!** Start your video conference

---

## 🎮 Control Buttons (Bottom Bar)

| Icon | Function | Action |
|------|----------|--------|
| 🎤 | **Mute/Unmute** | Toggle your microphone |
| 📹 | **Video On/Off** | Toggle your camera |
| 🖥️ | **Screen Share** | Share your screen |
| ✋ | **Raise Hand** | Signal you want to speak |
| 😊 | **Reaction** | Send emoji reaction |
| 🔴 | **Record** | Start/stop recording |
| ⚫ | **Leave** | Exit the room |

## 🎬 Recording Feature

### How to Record:
1. Join a room
2. Click **red circle button** 
3. Recording starts (indicator shows at top-right)
4. Click button again to stop
5. File downloads automatically as `.webm`

### Important Notes:
- Records YOUR audio/video only
- File name includes date/time
- Notifies all participants
- Stops automatically when you leave

## 🐛 Troubleshooting

### Can't see video?
1. Check camera permissions (browser address bar)
2. Verify other app not using camera
3. Refresh page and rejoin

### Can't hear audio?
1. Check microphone permissions
2. Click mute/unmute to toggle
3. Check system sound settings

### Recording not working?
1. Use Chrome or Edge browser
2. Update browser to latest version
3. Check available disk space

### Can't login from another device?
1. Verify username/password (case-sensitive)
2. Wait 30 seconds after account creation
3. Clear browser cache
