================================================================================
                        STEP-BY-STEP INSTRUCTIONS
================================================================================

Step 1: Open Application
   └─ Open index.html in your browser

Step 2: Navigate to Teachers
   └─ Click "Teachers" (👨‍🏫) in the left sidebar

Step 3: Go to Teacher Chat
   └─ Click "Teacher Chat" tab at the top

Step 4: Access CommHub Pro
   └─ Click "Group Video (CommHub Pro)" (🎥) tab
   
Step 5: Join a Room
   └─ Enter room name and click "Join Room"
   
Step 6: Allow Permissions
   └─ Grant camera and microphone access
   
Step 7: Start Conferencing! 🎉
   └─ You're now in CommHub Pro video call

================================================================================
                        TROUBLESHOOTING
================================================================================

Can't find CommHub Pro?
   → Check you're logged in as Teacher/Admin/HOD
   → Follow navigation path above exactly
   
Can't join room?
   → Check camera/microphone permissions
   → Verify signaling server is deployed
   
No video/audio?
   → Allow browser permissions
   → Check hardware connections
   
Need more help?
   → See COMMHUB_PRO_LOCATION.md for detailed docs
